---
title: 'GET /api/markets/:id/quote'
description: 'Price a buy or a sell of one outcome before it is placed'
---

Asks the market's AMM what a trade would return. You get the tokens a buy would receive, or the USDC a sell would release, the prices after the trade, and the protocol fee. Buy quotes also include an estimated payout. A quote is read-only and places nothing.

## Endpoint

```
GET https://app.kash.bot/api/markets/:id/quote
```

## Path parameters

<ParamField path="id" type="string" required>
  Market UUID.
</ParamField>

## Query parameters

<ParamField query="outcomeIndex" type="integer" required>
  The outcome to trade, from `0` to `outcomeCount - 1`.
</ParamField>

<ParamField query="action" type="string" required>
  `buy` or `sell`.
</ParamField>

<ParamField query="amount" type="string" required>
  A positive whole number in **atomic units**. For `buy` it is USDC to spend, with 6 decimals (`1000000` is 1 USDC). For `sell` it is outcome tokens to sell, as WAD with 18 decimals (`1000000000000000000` is 1 token).
</ParamField>

## Response

<ResponseField name="quote" type="object">
  <Expandable title="Quote (buy)">
    <ResponseField name="outcomeIndex" type="integer">The quoted outcome</ResponseField>
    <ResponseField name="action" type="string">`buy`</ResponseField>
    <ResponseField name="amountIn" type="string">USDC in, atomic</ResponseField>
    <ResponseField name="tokensOut" type="string">Outcome tokens received, WAD</ResponseField>
    <ResponseField name="reserveAfter" type="string">AMM reserve after the trade, WAD</ResponseField>
    <ResponseField name="c" type="string">AMM invariant after the trade, WAD</ResponseField>
    <ResponseField name="pAfter" type="string[]">Each outcome's marginal price after the trade, WAD</ResponseField>
    <ResponseField name="qAfter" type="string[]">Each outcome's token supply after the trade, WAD</ResponseField>
    <ResponseField name="effectivePrice" type="number">USDC paid per token</ResponseField>
    <ResponseField name="impliedProbability" type="number">The outcome's marginal price after the trade (0 to 1)</ResponseField>
    <ResponseField name="protocolTradeFeeBps" type="number">Protocol fee in basis points</ResponseField>
    <ResponseField name="estimate" type="object | null">
      Payout estimate in whole USDC: `youPayUsdc`, `protocolFeeUsdc`, `netIntoAmmUsdc`, `tokensReceived`, `payoutAtCurrentPriceUsdc` (what the position pays if it wins and prices stay where they are), `estimatedPayoutUsdc` and `snapshotPayoutUsdc` (the same value with a historical adjustment applied), `payoutUplift`, `payoutUpliftPercentile`, `impliedChanceAfter`, `effectiveBreakEvenChance` and `gasEstimateUsdc`. A promotional `promotionalEstimatedPayoutUsdc` string may also be present. It is display-only and does not change the trade. `estimate` is `null` when it can't be computed.
    </ResponseField>
  </Expandable>
  <Expandable title="Quote (sell)">
    <ResponseField name="action" type="string">`sell`</ResponseField>
    <ResponseField name="tokensIn" type="string">Tokens sold, WAD</ResponseField>
    <ResponseField name="usdcOut" type="string">USDC received, atomic</ResponseField>
    <ResponseField name="grossRelease" type="string">Gross value released by the AMM before fees, WAD</ResponseField>
    <ResponseField name="reserveAfter, c, pAfter, qAfter, effectivePrice, impliedProbability, protocolTradeFeeBps" type="…">As for buy</ResponseField>
    <ResponseField name="gasEstimateUsdc" type="number">Estimated network cost in whole USDC</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="market" type="object">
  `{ id, contractAddress, chainId, outcomes, status }`. The `outcomes` here carry the AMM's raw marginal `probability`, next to `impliedChance`.
</ResponseField>

<ResponseField name="units" type="object">
  Always `{ "usdc": "atomic-6", "token": "wad-18" }`.
</ResponseField>

## Errors

| Status | When |
|---|---|
| 400 | `amount` isn't a positive integer, `outcomeIndex` doesn't exist in this market, `action` is missing, or the market has no on-chain address yet |
| 404 | Unknown market |
| 503 | The chain read timed out. Retry after the `Retry-After` header. |

## Caching and rate limit

Market reads group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

<CodeGroup>
```bash cURL (buy 1 USDC of outcome 0)
curl "https://app.kash.bot/api/markets/93f1445c-912c-47b4-8065-d1ff5a6b8dfc/quote?outcomeIndex=0&action=buy&amount=1000000"
```

```javascript JavaScript
const usdc = 25;
const params = new URLSearchParams({
  outcomeIndex: '1',
  action: 'buy',
  amount: String(usdc * 1_000_000),
});
const res = await fetch(
  `https://app.kash.bot/api/markets/93f1445c-912c-47b4-8065-d1ff5a6b8dfc/quote?${params}`
);
const { quote } = await res.json();
console.log(`You get ${quote.estimate?.tokensReceived} tokens; pays ~$${quote.estimate?.payoutAtCurrentPriceUsdc} if it wins`);
```
</CodeGroup>
