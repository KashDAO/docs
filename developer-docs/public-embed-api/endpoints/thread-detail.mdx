title: 'GET /api/threads/:id'
description: 'Get one prediction market thread'
---

## Endpoint

```
GET https://app.kash.bot/api/threads/:id
```

## Path parameters

<ParamField path="id" type="string" required>
  Thread UUID.
</ParamField>

## Response

<ResponseField name="thread" type="Thread">
  A [thread object](/developer-docs/public-embed-api/endpoints/threads#response).
</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt, transformed, dataSource, threadId }`</ResponseField>

## Caching and rate limit

Thread detail group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/threads/00000001-0000-4000-a000-000000000001"
```

```javascript JavaScript
const res = await fetch('https://app.kash.bot/api/threads/00000001-0000-4000-a000-000000000001');
if (res.status === 404) throw new Error('Unknown thread');
const { thread } = await res.json();
```
</CodeGroup>
