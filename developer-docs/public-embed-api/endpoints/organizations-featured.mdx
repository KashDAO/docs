---
title: 'GET /api/organizations/featured'
description: 'Featured organizations ranked by market volume'
---

Returns active and trial organizations that have at least one verified market, sorted by lifetime volume (highest first), then by number of live markets. Use it to build a "creators" rail or to discover organization IDs.

The list also contains one combined entry, **Chiliz** (`slug: "chiliz"`), whose stats cover fan-token markets from every organization. It isn't a real organization record: its `id` returns `404` from the other organization endpoints, and its `logoUrl` is a path relative to app.kash.bot.

## Endpoint

```
GET https://app.kash.bot/api/organizations/featured
```

## Query parameters

<ParamField query="limit" type="integer">
  1 to 20. Leave it out to get every eligible organization.
</ParamField>

## Response

<ResponseField name="organizations" type="OrganizationProfile[]">
  The same shape as [`GET /api/organizations/:id/profile`](/developer-docs/public-embed-api/endpoints/organization-profile#response). `description` is always `null` here, and so is `websiteUrl` for every entry except Chiliz.
</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt }`</ResponseField>

## Caching and rate limit

Cached at the edge for 60 seconds, plus 120 seconds stale-while-revalidate. Organization and partner reads group: 600 requests per minute per IP.

## Example request

```bash cURL
curl "https://app.kash.bot/api/organizations/featured?limit=5"
```
