---
title: 'GET /api/organizations/:id/markets'
description: "List an organization's markets"
---

Returns the verified markets an organization owns, plus any markets on which it is the partner. It returns `404` for an unknown organization, and an empty list for an organization with no markets.

## Endpoint

```
GET https://app.kash.bot/api/organizations/:id/markets
```

## Path parameters

<ParamField path="id" type="string" required>
  Organization UUID.
</ParamField>

## Query parameters

<ParamField query="status" type="string" default="active">
  `active`, `resolved` or `all`, as for [`GET /api/markets`](/developer-docs/public-embed-api/endpoints/markets).
</ParamField>

<ParamField query="category" type="string">
  Category slug.
</ParamField>

<ParamField query="sortBy" type="string" default="created_at">
  `created_at`, `total_volume`, `current_probability`, `current_implied_chance`, `title` or `end_time`.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  `asc` or `desc`.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  1 to 500.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 10,000.
</ParamField>

## Response

<ResponseField name="markets" type="Market[]">
  [Market objects](/developer-docs/public-embed-api/endpoints/markets#response). Here `outcomes[].probability` is the AMM's raw marginal price and `oddsKnown` is not included, so show `outcomes[].impliedChance` as the odds.
</ResponseField>

<ResponseField name="pagination" type="object">`{ offset, limit, total, hasMore }`</ResponseField>

<ResponseField name="_meta" type="object">`{ organizationId, requestedAt }`</ResponseField>

## Caching and rate limit

Cached for 5 minutes, and for 60 seconds at the edge. Market reads group: 600 requests per minute per IP.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/organizations/6b617368-6277-6864-7800-000000000001/markets?sortBy=total_volume&limit=12"
```

```javascript JavaScript
const orgId = '6b617368-6277-6864-7800-000000000001';
const res = await fetch(`https://app.kash.bot/api/organizations/${orgId}/markets?limit=12`);
const { markets, pagination } = await res.json();
markets.forEach((m) => console.log(m.title, m.outcomes.map((o) => o.impliedChance)));
```
</CodeGroup>
