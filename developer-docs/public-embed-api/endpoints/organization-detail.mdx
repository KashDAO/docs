---
title: 'GET /api/organizations/:id'
description: 'Get public branding and metadata for an organization'
---

An organization is a tenant on Kash: Kash itself, or a white-label client that runs its own markets. This endpoint returns only public fields, such as branding and status. Use it to style an embed in the organization's colors.

## Endpoint

```
GET https://app.kash.bot/api/organizations/:id
```

## Path parameters

<ParamField path="id" type="string" required>
  Organization UUID. Slugs are not accepted. You can find an organization's ID as `organizationId` on its markets, or in [`GET /api/organizations/featured`](/developer-docs/public-embed-api/endpoints/organizations-featured).
</ParamField>

## Response

<ResponseField name="organization" type="Organization">
  <Expandable title="Organization">
    <ResponseField name="id" type="string">Organization UUID</ResponseField>
    <ResponseField name="name" type="string">Name</ResponseField>
    <ResponseField name="slug" type="string">URL slug, as used in `https://app.kash.bot/o/{slug}`</ResponseField>
    <ResponseField name="displayName" type="string">Display name</ResponseField>
    <ResponseField name="tagline" type="string">Short tagline (may be `""`)</ResponseField>
    <ResponseField name="description" type="string | null">Longer description</ResponseField>
    <ResponseField name="websiteUrl" type="string | null">Website</ResponseField>
    <ResponseField name="colorPrimary" type="string">Brand color as hex, for example `#FBD109`</ResponseField>
    <ResponseField name="logoUrl" type="string | null">Logo URL</ResponseField>
    <ResponseField name="status" type="string">`active`, `trial`, `suspended` or `cancelled`</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt }`</ResponseField>

## Caching and rate limit

Cached for 10 minutes. Organization and partner reads group: 600 requests per minute per IP.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/organizations/6b617368-6277-6864-7800-000000000001"
```

```javascript JavaScript
const res = await fetch(
  'https://app.kash.bot/api/organizations/6b617368-6277-6864-7800-000000000001'
);
const { organization } = await res.json();
document.documentElement.style.setProperty('--brand', organization.colorPrimary);
```
</CodeGroup>
