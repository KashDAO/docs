---
title: 'GET /api/partners/:id/threads'
description: "List a partner's threads"
---

Works the same way as [`GET /api/organizations/:id/threads`](/developer-docs/public-embed-api/endpoints/organization-threads), but for threads created under a partner.

## Endpoint

```
GET https://app.kash.bot/api/partners/:id/threads
```

## Path parameters

<ParamField path="id" type="string" required>
  Partner UUID (RFC 4122). Unknown partners return `404`.
</ParamField>

## Query parameters

<ParamField query="status" type="string" default="active">
  `active`, `upcoming`, `closed` or `all`.
</ParamField>

<ParamField query="sortBy" type="string" default="created_at">
  `created_at`, `start_time` or `total_volume`.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  `asc` or `desc`.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  1 to 500.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 10,000.
</ParamField>

## Response

<ResponseField name="threads" type="object[]">
  Thread summaries, in [the same shape as the organization threads endpoint](/developer-docs/public-embed-api/endpoints/organization-threads#response).
</ResponseField>

<ResponseField name="pagination" type="object">`{ offset, limit, total, hasMore }`</ResponseField>

<ResponseField name="_meta" type="object">`{ partnerId, requestedAt }`</ResponseField>

## Caching and rate limit

Cached for 5 minutes. Organization and partner reads group: 600 requests per minute per IP.

## Example request

```bash cURL
curl "https://app.kash.bot/api/partners/2be9da86-d048-4834-b0f6-d9fa26b9af48/threads?status=all"
```

## Example response

```json 200
{
  "threads": [],
  "pagination": { "offset": 0, "limit": 100, "total": 0, "hasMore": false },
  "_meta": {
    "partnerId": "2be9da86-d048-4834-b0f6-d9fa26b9af48",
    "requestedAt": "2026-10-20T17:46:19.866Z"
  }
}
```
