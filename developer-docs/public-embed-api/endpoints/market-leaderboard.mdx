---
title: 'GET /api/markets/:id/leaderboard'
description: 'Positions in one market, ranked by size'
---

Lists the traders in one market, ranked by the amount they put in (largest first). Profit and loss figures are not exposed.

## Endpoint

```
GET https://app.kash.bot/api/markets/:id/leaderboard
```

## Path parameters

<ParamField path="id" type="string" required>
  Market UUID.
</ParamField>

## Query parameters

<ParamField query="limit" type="integer" default="25">
  1 to 50.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 10,000.
</ParamField>

## Response

<ResponseField name="entries" type="Entry[]">
  <Expandable title="Entry">
    <ResponseField name="rank" type="integer">1-based rank by `amount`</ResponseField>
    <ResponseField name="userId" type="string">Kash user UUID</ResponseField>
    <ResponseField name="address" type="string">Trading wallet address</ResponseField>
    <ResponseField name="username" type="string | null">Display name</ResponseField>
    <ResponseField name="handle" type="string | null">X handle</ResponseField>
    <ResponseField name="profilePictureUrl" type="string | null">Avatar</ResponseField>
    <ResponseField name="titleDisplayName" type="string | null">The trader's displayed title</ResponseField>
    <ResponseField name="titleRarity" type="string | null">Title rarity</ResponseField>
    <ResponseField name="outcomeIndex" type="integer">The trader's main outcome</ResponseField>
    <ResponseField name="outcomeIndices" type="integer[]">Every outcome the trader holds</ResponseField>
    <ResponseField name="outcomeLabel" type="string">Label of `outcomeIndex`</ResponseField>
    <ResponseField name="outcomeColor" type="string | null">The outcome's display color</ResponseField>
    <ResponseField name="outcomeImageUrl" type="string | null">The outcome's image</ResponseField>
    <ResponseField name="amount" type="number">Amount put in, in atomic USDC</ResponseField>
    <ResponseField name="currentValue" type="number">Current value of the position, in atomic USDC</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="_meta" type="object">
  `{ marketId, marketStatus, winningOutcomeIndex, resolvedAt, entryCount, totalEntries, returnedCount, limit, offset, hasMore }`. `totalEntries` is the number of ranked traders across all pages.
</ResponseField>

## Caching and rate limit

Leaderboards group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

```bash cURL
curl "https://app.kash.bot/api/markets/93f1445c-912c-47b4-8065-d1ff5a6b8dfc/leaderboard?limit=10"
```
