---
title: 'GET /api/markets/:id/twitter-link'
description: 'Build an X (Twitter) deep link that places a prediction on one market'
---

Returns a `twitter.com/intent/tweet` URL with the tweet already written: the outcome, the amount and the account to mention. A user who has connected their X account to Kash can post it, and the Kash trading bot reads the tweet and submits the trade from the user's own wallet. Use it to build your own "Predict" buttons without an iframe.

## Endpoint

```
GET https://app.kash.bot/api/markets/:id/twitter-link
```

## Path parameters

<ParamField path="id" type="string" required>
  Market UUID.
</ParamField>

## Query parameters

<ParamField query="outcomeIndex" type="integer" required>
  The outcome you expect, from `0` to `outcomeCount - 1`.
</ParamField>

<ParamField query="amount" type="number" required>
  The trade amount in whole USDC, from 1 to 10,000.
</ParamField>

<ParamField query="locale" type="string">
  The language of the tweet: `en`, `es`, `zh`, `pt` or `ru`. Defaults to English.
</ParamField>

## How the tweet is built

- **Mention.** The tweet mentions the X account that trades on this market (the market's `marketBotHandle`). If the market has none, it mentions the Kash trading bot.
- **Outcome text.** Outcome `0` is written as `Yes`, outcome `1` as `No`, and any other outcome as `Outcome N`, counting from 1. To use the market's real outcome labels, call [`POST /api/twitter-links`](/developer-docs/public-embed-api/endpoints/twitter-links-batch) instead.
- **Quote or link.** If the market was announced on X, the announcement tweet's URL is added to the text, which makes the post a quote tweet. Otherwise the intent URL carries a `url` parameter that points to the market page on app.kash.bot.

## Response

<ResponseField name="twitterUrl" type="string">The intent URL to open</ResponseField>
<ResponseField name="tweetContent" type="string">The tweet text, including the quoted URL when there is one</ResponseField>
<ResponseField name="market" type="object">`{ id, question, sourceTweetUrl }`</ResponseField>

## Errors

| Status | When |
|---|---|
| 400 `VALIDATION_ERROR` | A parameter is missing or out of range, or the market isn't accepting predictions (it isn't `ACTIVE`, or it has expired). In the second case, `details.market` is `{ id, question, status, isExpired }`. |
| 404 `NOT_FOUND` | Unknown market |

## Caching and rate limit

Market reads group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/markets/93f1445c-912c-47b4-8065-d1ff5a6b8dfc/twitter-link?outcomeIndex=0&amount=10"
```

```javascript JavaScript
async function predictOnX(marketId, outcomeIndex, amount) {
  const params = new URLSearchParams({ outcomeIndex, amount });
  const res = await fetch(
    `https://app.kash.bot/api/markets/${marketId}/twitter-link?${params}`
  );
  const body = await res.json();
  if (!res.ok) throw new Error(body.message);
  window.open(body.twitterUrl, '_blank', 'noopener');
}
```
</CodeGroup>
