---
title: 'GET /api/markets/:id'
description: 'Get one market, optionally with price history and recent trades'
---

Returns one market with the same fields as [`GET /api/markets`](/developer-docs/public-embed-api/endpoints/markets). You can also ask for its price history, its recent trades and an AI-written summary.

## Endpoint

```
GET https://app.kash.bot/api/markets/:id
```

## Path parameters

<ParamField path="id" type="string" required>
  Market UUID.
</ParamField>

## Query parameters

<ParamField query="history" type="boolean" default="false">
  Include `priceHistory`.
</ParamField>

<ParamField query="trades" type="boolean" default="false">
  Include `recentTrades`.
</ParamField>

<ParamField query="trades_limit" type="integer" default="100">
  How many recent trades to return, 1 to 500.
</ParamField>

## Response

<ResponseField name="market" type="Market">
  A [market object](/developer-docs/public-embed-api/endpoints/markets#response). Prices are normalized as described there, and `priceKnown` is included.
</ResponseField>

<ResponseField name="priceHistory" type="object[]">
  Only present when `history=true`. Each point is `{ timestamp, price, probability, volume }`. `volume` is atomic USDC.
</ResponseField>

<ResponseField name="recentTrades" type="object[]">
  Only present when `trades=true`. Newest first. Useful fields: `id`, `outcomeIndex`, `tradeType` (`buy` or `sell`), `usdcIn` and `tokensOut` (buys), `usdcOut` and `tokensIn` (sells), `price`, `probability`, `traderAddress`, `transactionHash`, `chainId` and `timestamp`. USDC values are atomic strings and token values are WAD strings.
</ResponseField>

<ResponseField name="aiInsight" type="object | null">
  `{ summary, aiModel, createdAt }`: an AI-generated background summary, or `null`.
</ResponseField>

<ResponseField name="_meta" type="object">
  `{ requestedAt, transformed, includes: { history, trades, tradesCount } }`
</ResponseField>

## Caching

Priced markets are cached at the edge for 5 seconds, plus 5 seconds stale-while-revalidate. A market that is still being indexed, and so has no outcomes yet, is sent with `Cache-Control: private, no-store`. Poll it until `outcomes` is filled in.

## Rate limit

Market reads group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/markets/93f1445c-912c-47b4-8065-d1ff5a6b8dfc?history=true&trades=true&trades_limit=5"
```

```javascript JavaScript
const id = '93f1445c-912c-47b4-8065-d1ff5a6b8dfc';
const res = await fetch(`https://app.kash.bot/api/markets/${id}?history=true`);
if (res.status === 404) throw new Error('Unknown market');
const { market, priceHistory } = await res.json();
console.log(market.title, market.outcomes[0].impliedChance, priceHistory.length);
```
</CodeGroup>
