---
title: 'GET /api/threads'
description: 'List prediction market threads'
---

A thread is a curated collection of related markets with its own start and end time. This endpoint lists threads across the whole platform.

## Endpoint

```
GET https://app.kash.bot/api/threads
```

## Query parameters

<ParamField query="status" type="string" default="active">
  `active` returns threads whose start time has passed and whose end time hasn't. `upcoming` returns threads that haven't started. `closed` returns threads that have ended. A thread without both a start and an end time is never `active`. `all` is accepted but currently returns the same set as `active`.
</ParamField>

<ParamField query="ownedBy" type="string">
  Only threads created by this user (UUID).
</ParamField>

<ParamField query="sortBy" type="string" default="created_at">
  `created_at`, `start_time` or `total_volume`.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  `asc` or `desc`.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  1 to 500.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 10,000.
</ParamField>

## Response

<ResponseField name="threads" type="Thread[]">
  <Expandable title="Thread">
    <ResponseField name="id" type="string">Thread UUID</ResponseField>
    <ResponseField name="title" type="string">Title</ResponseField>
    <ResponseField name="description" type="string">Description (`""` if none)</ResponseField>
    <ResponseField name="image" type="string">Image URL (`""` if none)</ResponseField>
    <ResponseField name="backgroundImage" type="string">Background image URL, when set</ResponseField>
    <ResponseField name="status" type="string">`upcoming`, `active` or `completed`</ResponseField>
    <ResponseField name="isActive" type="boolean">`true` when `status` is `active`</ResponseField>
    <ResponseField name="startTime" type="string">ISO 8601, when set</ResponseField>
    <ResponseField name="endTime" type="string">ISO 8601. If the thread has no end time, this is the time of the request.</ResponseField>
    <ResponseField name="marketCount" type="integer">Number of markets</ResponseField>
    <ResponseField name="totalVolume" type="number">Volume across the thread's markets, in atomic USDC</ResponseField>
    <ResponseField name="participantCount" type="integer">Number of distinct traders</ResponseField>
    <ResponseField name="category" type="string">Category ID, when set</ResponseField>
    <ResponseField name="topUsers" type="array">Always empty</ResponseField>
    <ResponseField name="createdAt" type="string">ISO 8601</ResponseField>
    <ResponseField name="updatedAt" type="string">ISO 8601</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">`{ offset, limit, total, hasMore }`</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt, transformed, dataSource, filters }`. `filters` repeats the query you sent.</ResponseField>

## Caching and rate limit

Thread list group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/threads?status=upcoming&sortBy=start_time&sortOrder=asc&limit=10"
```

```javascript JavaScript
const res = await fetch('https://app.kash.bot/api/threads?status=active&limit=20');
const { threads, pagination } = await res.json();
threads.forEach((t) => console.log(t.title, t.marketCount));
```
</CodeGroup>
