---
title: 'GET /api/organizations/:id/threads'
description: "List an organization's threads"
---

## Endpoint

```
GET https://app.kash.bot/api/organizations/:id/threads
```

## Path parameters

<ParamField path="id" type="string" required>
  Organization UUID. Unknown organizations return `404`.
</ParamField>

## Query parameters

<ParamField query="status" type="string" default="active">
  `active` returns threads that have started and not ended. `upcoming` returns threads that haven't started. `closed` returns threads that have ended. `all` returns every thread. A thread without a start and end time only appears under `all`.
</ParamField>

<ParamField query="sortBy" type="string" default="created_at">
  `created_at`, `start_time` or `total_volume`.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  `asc` or `desc`.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  1 to 500.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 10,000.
</ParamField>

## Response

<ResponseField name="threads" type="object[]">
  <Expandable title="Thread summary">
    <ResponseField name="id" type="string">Thread UUID</ResponseField>
    <ResponseField name="title" type="string">Title</ResponseField>
    <ResponseField name="description" type="string | null">Description</ResponseField>
    <ResponseField name="image" type="string | null">Image URL</ResponseField>
    <ResponseField name="status" type="string">Stored thread status</ResponseField>
    <ResponseField name="startTime" type="string | null">Start time</ResponseField>
    <ResponseField name="endTime" type="string | null">End time</ResponseField>
    <ResponseField name="marketCount" type="integer">Number of markets</ResponseField>
    <ResponseField name="totalVolume" type="string">Volume in atomic USDC</ResponseField>
    <ResponseField name="participantCount" type="integer">Number of distinct traders</ResponseField>
    <ResponseField name="createdAt" type="string">Creation time</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">`{ offset, limit, total, hasMore }`</ResponseField>

<ResponseField name="_meta" type="object">`{ organizationId, requestedAt }`</ResponseField>

<Note>
This summary shape is different from the thread object returned by [`GET /api/threads`](/developer-docs/public-embed-api/endpoints/threads). Here `totalVolume` is a string, empty values are `null` rather than `""`, and timestamps are Postgres timestamp strings.
</Note>

## Caching and rate limit

Cached for 5 minutes. Organization and partner reads group: 600 requests per minute per IP.

## Example request

```bash cURL
curl "https://app.kash.bot/api/organizations/6b617368-6277-6864-7800-000000000001/threads?status=all"
```
