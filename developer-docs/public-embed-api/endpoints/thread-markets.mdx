---
title: 'GET /api/threads/:id/markets'
description: 'List the markets in a thread'
---

Returns the markets in one thread. It returns `404` if the thread doesn't exist, and an empty list if the thread has no matching markets.

## Endpoint

```
GET https://app.kash.bot/api/threads/:id/markets
```

## Path parameters

<ParamField path="id" type="string" required>
  Thread UUID.
</ParamField>

## Query parameters

<ParamField query="status" type="string" default="active">
  `active`, `resolved` or `all`, as for [`GET /api/markets`](/developer-docs/public-embed-api/endpoints/markets).
</ParamField>

<ParamField query="sortBy" type="string" default="created_at">
  `created_at`, `total_volume`, `current_probability`, `current_implied_chance`, `title` or `end_time`.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  `asc` or `desc`.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  1 to 500.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 10,000.
</ParamField>

## Response

<ResponseField name="markets" type="Market[]">
  [Market objects](/developer-docs/public-embed-api/endpoints/markets#response), with one difference: `outcomes[].probability` is the AMM's raw marginal price and `priceKnown` is not included. Show `outcomes[].impliedChance` as the implied probability.
</ResponseField>

<ResponseField name="pagination" type="object">`{ offset, limit, total, hasMore }`</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt, transformed, dataSource, threadId, threadTitle, filters }`</ResponseField>

## Caching and rate limit

Thread markets group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/threads/00000001-0000-4000-a000-000000000003/markets?sortBy=total_volume&limit=20"
```

```javascript JavaScript
const threadId = '00000001-0000-4000-a000-000000000003';
const res = await fetch(`https://app.kash.bot/api/threads/${threadId}/markets?limit=20`);
const { markets, _meta } = await res.json();
console.log(_meta.threadTitle, markets.length);
```
</CodeGroup>
