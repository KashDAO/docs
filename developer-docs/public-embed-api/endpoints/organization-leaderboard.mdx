---
title: 'GET /api/organizations/:id/leaderboard'
description: "Top traders on an organization's markets"
---

Ranks traders by their results on the markets an organization owns or is the partner on. Stats cover only those markets. Traders are ranked by lifetime winnings, then by volume.

## Endpoint

```
GET https://app.kash.bot/api/organizations/:id/leaderboard
```

## Path parameters

<ParamField path="id" type="string" required>
  Organization UUID. Unknown organizations return `404`.
</ParamField>

## Query parameters

<ParamField query="category" type="string">
  `winners` returns only traders with positive lifetime winnings. `losers` is accepted but currently always returns an empty list. Leave it out to get every trader.
</ParamField>

<ParamField query="limit" type="integer" default="20">
  1 to 200.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 100,000.
</ParamField>

## Response

<ResponseField name="leaderboard" type="Entry[]">
  The requested page. `entries` holds the same array.

  <Expandable title="Entry">
    <ResponseField name="rank" type="integer">1-based rank</ResponseField>
    <ResponseField name="userId" type="string">Kash user UUID</ResponseField>
    <ResponseField name="address" type="string">Wallet address. The same user can appear once per wallet, for example one Base and one Solana wallet.</ResponseField>
    <ResponseField name="displayName" type="string | null">Display name</ResponseField>
    <ResponseField name="username" type="string | null">Username</ResponseField>
    <ResponseField name="profilePictureUrl" type="string | null">Avatar</ResponseField>
    <ResponseField name="bannerUrl" type="string | null">Profile banner</ResponseField>
    <ResponseField name="totalVolume" type="number">Volume on this organization's markets, in atomic USDC</ResponseField>
    <ResponseField name="payoutsReceived" type="number">Payouts received, in atomic USDC</ResponseField>
    <ResponseField name="lifetimeWinnings" type="number">Lifetime winnings, in atomic USDC</ResponseField>
    <ResponseField name="totalTrades" type="integer">Number of trades</ResponseField>
    <ResponseField name="winRate" type="number">Win rate as a percentage (0 to 100)</ResponseField>
    <ResponseField name="titleSlug, titleDisplayName, titleRarity" type="string | null">The trader's displayed title</ResponseField>
    <ResponseField name="organizationAffiliation" type="object | null">The organization the trader is affiliated with, if any</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="winners" type="Entry[]">The top five traders with positive winnings, whatever page you requested</ResponseField>
<ResponseField name="losers" type="Entry[]">Always empty</ResponseField>
<ResponseField name="pagination" type="object">`{ offset, limit, total, hasMore }`</ResponseField>
<ResponseField name="uniqueTraders" type="integer">Number of ranked traders</ResponseField>
<ResponseField name="_meta" type="object">`{ requestedAt, organizationId }`</ResponseField>

## Caching and rate limit

Cached for 5 minutes. Leaderboards group: 300 requests per minute per IP.

## Example request

```bash cURL
curl "https://app.kash.bot/api/organizations/6b617368-6277-6864-7800-000000000001/leaderboard?limit=10"
```
