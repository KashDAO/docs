---
title: 'GET /api/partners/:id'
description: 'Get public branding and metadata for a partner'
---

A partner is a partner-tier organization that a host organization onboards to create markets under its brand. Partners are organizations themselves, so the fields match [`GET /api/organizations/:id`](/developer-docs/public-embed-api/endpoints/organization-detail), plus `organizationId`, the host organization.

## Endpoint

```
GET https://app.kash.bot/api/partners/:id
```

## Path parameters

<ParamField path="id" type="string" required>
  Partner UUID. It must be a standard RFC 4122 UUID, and anything else returns `400`. Unknown partners return `404`.
</ParamField>

## Response

<ResponseField name="partner" type="Partner">
  <Expandable title="Partner">
    <ResponseField name="id" type="string">Partner UUID</ResponseField>
    <ResponseField name="organizationId" type="string">The host organization's UUID</ResponseField>
    <ResponseField name="name" type="string">Name</ResponseField>
    <ResponseField name="slug" type="string">URL slug</ResponseField>
    <ResponseField name="displayName" type="string">Display name</ResponseField>
    <ResponseField name="tagline" type="string">Tagline (may be `""`)</ResponseField>
    <ResponseField name="description" type="string | null">Description</ResponseField>
    <ResponseField name="websiteUrl" type="string | null">Website</ResponseField>
    <ResponseField name="colorPrimary" type="string">Brand color as hex</ResponseField>
    <ResponseField name="logoUrl" type="string | null">Logo URL</ResponseField>
    <ResponseField name="status" type="string">`active`, `trial`, `suspended` or `cancelled`</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt }`</ResponseField>

## Caching and rate limit

Cached for 10 minutes. Organization and partner reads group: 600 requests per minute per IP.

## Example request

```bash cURL
curl "https://app.kash.bot/api/partners/2be9da86-d048-4834-b0f6-d9fa26b9af48"
```
