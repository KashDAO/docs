---
title: 'GET /api/threads/:id/twitter-links'
description: 'X (Twitter) deep links for every open market in a thread'
---

Returns two deep links, one for outcome 0 and one for outcome 1, for every market in a thread that is verified, tradeable and not expired. Use it to render a whole thread with your own UI. For a single market, or for outcomes beyond the first two, use [`GET /api/markets/:id/twitter-link`](/developer-docs/public-embed-api/endpoints/market-twitter-link) or [`POST /api/twitter-links`](/developer-docs/public-embed-api/endpoints/twitter-links-batch).

## Endpoint

```
GET https://app.kash.bot/api/threads/:id/twitter-links
```

## Path parameters

<ParamField path="id" type="string" required>
  Thread UUID.
</ParamField>

## Query parameters

<ParamField query="amount" type="number" default="10">
  The trade amount in whole USDC, from 1 to 10,000.
</ParamField>

<ParamField query="locale" type="string">
  The language of the tweet: `en`, `es`, `zh`, `pt` or `ru`.
</ParamField>

## Response

<ResponseField name="thread" type="object">`{ id, title, description }`</ResponseField>

<ResponseField name="markets" type="object[]">
  <Expandable title="Market links">
    <ResponseField name="marketId" type="string">Market UUID</ResponseField>
    <ResponseField name="question" type="string">Market title</ResponseField>
    <ResponseField name="outcome0Link" type="string">Intent URL for outcome 0, written as `Yes`</ResponseField>
    <ResponseField name="outcome1Link" type="string">Intent URL for outcome 1, written as `No`</ResponseField>
    <ResponseField name="outcome0TweetContent" type="string">Tweet text for outcome 0</ResponseField>
    <ResponseField name="outcome1TweetContent" type="string">Tweet text for outcome 1</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt, amount, totalMarkets }`</ResponseField>

Each tweet mentions the X account that posts the market, or the Kash trading bot if there is none. These links don't quote the market's announcement tweet.

## Rate limit

Market reads group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/threads/00000001-0000-4000-a000-000000000003/twitter-links?amount=25"
```

```javascript JavaScript
const res = await fetch(
  'https://app.kash.bot/api/threads/00000001-0000-4000-a000-000000000003/twitter-links?amount=25'
);
const { thread, markets } = await res.json();
for (const m of markets) {
  console.log(m.question, m.outcome0Link, m.outcome1Link);
}
```
</CodeGroup>
