---
title: 'GET /api/organizations/:id/partners'
description: 'List the partners an organization hosts'
---

A partner is a partner-tier organization that a host organization onboards to create markets under the host's brand. This endpoint lists an organization's partners.

## Endpoint

```
GET https://app.kash.bot/api/organizations/:id/partners
```

## Path parameters

<ParamField path="id" type="string" required>
  The host organization's UUID. Unknown organizations return `404`.
</ParamField>

## Query parameters

<ParamField query="status" type="string" default="active">
  `active` returns partners whose status is `active`. `inactive` returns partners in any other status (`trial`, `suspended` or `cancelled`). `all` returns both.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  1 to 500.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 10,000.
</ParamField>

## Response

<ResponseField name="partners" type="Partner[]">
  Each item has the fields described in [`GET /api/partners/:id`](/developer-docs/public-embed-api/endpoints/partner-detail#response).
</ResponseField>

<ResponseField name="pagination" type="object">`{ offset, limit, total, hasMore }`</ResponseField>

<ResponseField name="_meta" type="object">`{ organizationId, requestedAt }`</ResponseField>

## Caching and rate limit

Cached for 5 minutes. Organization and partner reads group: 600 requests per minute per IP.

## Example request

```bash cURL
curl "https://app.kash.bot/api/organizations/6b617368-6277-6864-7800-000000000001/partners?status=all"
```
