---
title: 'POST /api/twitter-links'
description: 'Build X (Twitter) deep links for up to 50 market and outcome pairs in one request'
---

Builds deep links in bulk, using each market's real outcome labels. One request can mix markets, outcomes and amounts. If one entry is invalid, it lands in `errors` and the rest of the batch is still returned.

<Warning>
**Server-side only.** This endpoint is CSRF-protected. Each request needs the `csrf-token` cookie from `GET /api/csrf` and the same value in an `x-csrf-token` header. Browsers on other origins can't do that, because the cookie is `SameSite=Strict` and the API's wildcard CORS doesn't allow credentials. Call it from your backend. In a browser, call [`GET /api/markets/:id/twitter-link`](/developer-docs/public-embed-api/endpoints/market-twitter-link) once per market instead.
</Warning>

## Endpoint

```
POST https://app.kash.bot/api/twitter-links
```

## Headers

<ParamField header="Content-Type" type="string" required>
  `application/json`
</ParamField>

<ParamField header="Cookie" type="string" required>
  `csrf-token=<value>`, the cookie set by `GET /api/csrf`.
</ParamField>

<ParamField header="x-csrf-token" type="string" required>
  The same token, URL-decoded. The cookie is URL-encoded, so `%3D` becomes `=`.
</ParamField>

## Request body

<ParamField body="markets" type="object[]" required>
  1 to 50 entries.

  <Expandable title="Entry">
    <ParamField body="marketId" type="string" required>Market UUID</ParamField>
    <ParamField body="outcomeIndex" type="integer" required>The outcome you expect, from 0 to 99</ParamField>
    <ParamField body="amount" type="number" required>Trade amount in whole USDC, from 1 to 10,000</ParamField>
    <ParamField body="outcomeLabel" type="string">Optional. It must be one of the market's own labels for this outcome, or the default name (`Yes`, `No` or `Outcome N`). If it isn't, the entry fails with `Outcome is not one of the market's`. Leave it out to use the market's label.</ParamField>
  </Expandable>
</ParamField>

## Response

<ResponseField name="links" type="object[]">
  `{ marketId, question, twitterUrl, tweetContent, outcomeIndex, outcomeLabel, amount }` for each entry that succeeded.
</ResponseField>

<ResponseField name="errors" type="object[]">
  `{ marketId, outcomeIndex, error }` for each entry that failed. `error` is `Market not found`, `Market is expired`, `Market is not active` or `Outcome is not one of the market's`.
</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt, totalRequested, totalGenerated, totalErrors }`</ResponseField>

Only verified markets that are `ACTIVE` or frozen, and not past their end time, get links. Each tweet mentions the X account that posts the market, or the Kash trading bot if there is none. These links don't quote the announcement tweet.

## Rate limit

Rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)).

## Example request

<CodeGroup>
```bash cURL
curl -s -c kash-cookies.txt -o /dev/null https://app.kash.bot/api/csrf
RAW=$(awk '$6 == "csrf-token" { print $7 }' kash-cookies.txt)
TOKEN=$(python3 -c 'import sys, urllib.parse; print(urllib.parse.unquote(sys.argv[1]))' "$RAW")

curl -s -b kash-cookies.txt \
  -H "x-csrf-token: $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"markets":[{"marketId":"93f1445c-912c-47b4-8065-d1ff5a6b8dfc","outcomeIndex":1,"amount":25}]}' \
  https://app.kash.bot/api/twitter-links
```

```javascript Node.js 18+
const BASE = 'https://app.kash.bot';

async function getCsrf() {
  const res = await fetch(`${BASE}/api/csrf`);
  const setCookie = res.headers.getSetCookie().find((c) => c.startsWith('csrf-token='));
  const raw = setCookie.split(';')[0].slice('csrf-token='.length);
  return { cookie: `csrf-token=${raw}`, token: decodeURIComponent(raw) };
}

const { cookie, token } = await getCsrf(); // reusable for 24 hours
const res = await fetch(`${BASE}/api/twitter-links`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', Cookie: cookie, 'x-csrf-token': token },
  body: JSON.stringify({
    markets: [
      { marketId: '93f1445c-912c-47b4-8065-d1ff5a6b8dfc', outcomeIndex: 1, amount: 25 },
      { marketId: '00000000-0000-4000-8000-000000000000', outcomeIndex: 0, amount: 5 },
    ],
  }),
});
const { links, errors } = await res.json();
```
</CodeGroup>
