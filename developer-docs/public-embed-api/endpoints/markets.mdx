---
title: 'GET /api/markets'
description: 'List, filter and search prediction markets'
---

Returns a page of verified markets. With no parameters you get active markets, newest first.

## Endpoint

```
GET https://app.kash.bot/api/markets
```

## Query parameters

<ParamField query="status" type="string" default="active">
  `active`, `resolved` or `all`. `active` includes markets that have passed their end time but are still waiting to resolve. `all` returns every market. `cancelled`, `paused` and `refunded` are accepted but currently return the same set as `active`.
</ParamField>

<ParamField query="active" type="string">
  `true`/`1` or `false`/`0`. A shortcut that overrides `status`: `true` returns active markets and `false` returns resolved markets.
</ParamField>

<ParamField query="tradableOnly" type="boolean" default="false">
  Applies to the active set only. When `true`, frozen and expired markets are left out, so every result can still be traded.
</ParamField>

<ParamField query="search" type="string">
  Matches against market titles and descriptions. Every word must match. 1 to 120 characters.
</ParamField>

<ParamField query="category" type="string">
  A category slug, such as `football` or `business`. [`/api/markets/category-stats`](/developer-docs/public-embed-api/endpoints/market-category-stats) lists the slugs.
</ParamField>

<ParamField query="threadId" type="string">
  Only markets in this thread (UUID). `thread_id` is also accepted.
</ParamField>

<ParamField query="chapterId" type="string">
  Only markets in this chapter.
</ParamField>

<ParamField query="ids" type="string">
  A comma-separated list of up to 100 market UUIDs.
</ParamField>

<ParamField query="creatorOwned" type="boolean" default="false">
  When `true`, returns only markets created by creators rather than by Kash.
</ParamField>

<ParamField query="fanTokenRedemption" type="string">
  `true` or `false`. Filters on whether the market has an active fan-token redemption option.
</ParamField>

<ParamField query="resolvedAfter" type="integer">
  Earliest resolution time, in epoch seconds. Use it with `status=resolved` or `status=all`.
</ParamField>

<ParamField query="resolvedBefore" type="integer">
  Latest resolution time, in epoch seconds.
</ParamField>

<ParamField query="sortBy" type="string" default="created_at">
  `created_at`, `total_volume`, `current_probability`, `current_implied_chance`, `title` or `end_time`.
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  `asc` or `desc`.
</ParamField>

<ParamField query="limit" type="integer" default="100">
  1 to 500.
</ParamField>

<ParamField query="offset" type="integer" default="0">
  0 to 10,000.
</ParamField>

## Response

<ResponseField name="markets" type="Market[]">
  Each market object has the fields below. Markets carry more fields than this list, but those extra fields are internal and may change.

  <Expandable title="Market">
    <ResponseField name="id" type="string">Market UUID</ResponseField>
    <ResponseField name="title" type="string">The market question. `question` holds the same value.</ResponseField>
    <ResponseField name="description" type="string | null">Longer description</ResponseField>
    <ResponseField name="resolutionCriteria" type="string | null">How the market settles</ResponseField>
    <ResponseField name="resolutionSources" type="object[]">`{ name, url, imageUrl }` for each source used to settle the market</ResponseField>
    <ResponseField name="links" type="object[]">`{ title, url, linkType, displayOrder }`: related links</ResponseField>
    <ResponseField name="status" type="string">`UNSEEDED`, `ACTIVE`, `RESOLVED`, `ABANDONED` or `CANCELLED`</ResponseField>
    <ResponseField name="tradable" type="boolean">`true` while trading is open</ResponseField>
    <ResponseField name="frozen" type="boolean">`true` once trading has stopped but the market hasn't resolved yet</ResponseField>
    <ResponseField name="isResolved" type="boolean">`true` once the market is resolved</ResponseField>
    <ResponseField name="winningOutcomeIndex" type="integer | null">The winning outcome, once resolved</ResponseField>
    <ResponseField name="cancelledAt" type="string | null">Set if the market was cancelled</ResponseField>
    <ResponseField name="endTime" type="number">End of the market, in **milliseconds** since the epoch</ResponseField>
    <ResponseField name="expiresAt" type="number">End of the market, in seconds since the epoch</ResponseField>
    <ResponseField name="freezeAt" type="number | null">When trading stops, in seconds since the epoch</ResponseField>
    <ResponseField name="resolveTime" type="number | null">When the market was resolved, in seconds since the epoch</ResponseField>
    <ResponseField name="chainId" type="number">`9000001` (Solana) or `8453` (Base, older markets only)</ResponseField>
    <ResponseField name="contractAddress" type="string">On-chain market address (base58 on Solana, `0x` on Base)</ResponseField>
    <ResponseField name="outcomeCount" type="integer">Number of outcomes</ResponseField>
    <ResponseField name="outcomes" type="object[]">
      `{ outcomeIndex, tokenId, label, weight, shareSupply, probability, impliedChance }`. `impliedChance` is the displayed implied probability (0 to 1), and `probability` is set to the same value. `weight` and `shareSupply` are WAD strings.
    </ResponseField>
    <ResponseField name="priceKnown" type="boolean">`false` when there is no price yet, so the prices are only a placeholder</ResponseField>
    <ResponseField name="currentImpliedChance" type="number">Implied probability of outcome 0</ResponseField>
    <ResponseField name="currentProbability" type="number">AMM marginal price for outcome 0. Not normalized, so show `currentImpliedChance` instead.</ResponseField>
    <ResponseField name="totalVolume" type="number">Lifetime volume in atomic USDC (6 decimals)</ResponseField>
    <ResponseField name="volume24h" type="number">Volume over the last 24 hours, in atomic USDC</ResponseField>
    <ResponseField name="seedAmountAtomic" type="string">Opening liquidity in atomic USDC</ResponseField>
    <ResponseField name="tradeCount" type="integer">Number of trades</ResponseField>
    <ResponseField name="participantCount" type="integer">Number of distinct traders</ResponseField>
    <ResponseField name="tradingFee" type="number">Trading fee as a fraction of the trade amount</ResponseField>
    <ResponseField name="minTrade" type="number">Smallest trade, in atomic USDC</ResponseField>
    <ResponseField name="maxTrade" type="number">Largest trade, in atomic USDC</ResponseField>
    <ResponseField name="category" type="string | null">Category slug</ResponseField>
    <ResponseField name="categoryLabel" type="string | null">Category display name</ResponseField>
    <ResponseField name="subCategory" type="string | null">Subcategory slug</ResponseField>
    <ResponseField name="subCategoryLabel" type="string | null">Subcategory display name</ResponseField>
    <ResponseField name="bannerImageUrl" type="string | null">HTTPS banner image URL</ResponseField>
    <ResponseField name="imageUrl" type="string | null">Image URI from the market metadata (may be `ipfs://`)</ResponseField>
    <ResponseField name="creator" type="string | null">Creator's display name</ResponseField>
    <ResponseField name="creatorUsername" type="string | null">Creator's username</ResponseField>
    <ResponseField name="creatorAvatarUrl" type="string | null">Creator's avatar</ResponseField>
    <ResponseField name="sourceTweetUrl" type="string | null">The tweet that announced the market</ResponseField>
    <ResponseField name="marketBotHandle" type="string | null">The X handle that trade tweets for this market should mention</ResponseField>
    <ResponseField name="createdAt" type="string">When the market was created</ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">`{ offset, limit, total, hasMore }`</ResponseField>

<ResponseField name="_meta" type="object">`{ requestedAt, cached, computed }`</ResponseField>

## Rate limit

Market reads group, rate-limited per IP (see [Rate limits](/developer-docs/public-embed-api/overview#rate-limits)). Responses may be served from a short-lived cache.

## Example request

<CodeGroup>
```bash cURL
curl "https://app.kash.bot/api/markets?status=active&tradableOnly=true&sortBy=total_volume&limit=10"
```

```javascript JavaScript
const params = new URLSearchParams({
  status: 'active',
  tradableOnly: 'true',
  sortBy: 'total_volume',
  limit: '10',
});
const res = await fetch(`https://app.kash.bot/api/markets?${params}`);
const { markets, pagination } = await res.json();

for (const m of markets) {
  const prices = m.outcomes.map((o) => `${o.label} ${(o.impliedChance * 100).toFixed(0)}%`);
  console.log(m.title, prices.join(' / '));
}
```

```python Python
import requests

res = requests.get(
    "https://app.kash.bot/api/markets",
    params={"status": "resolved", "resolvedAfter": 1790000000, "limit": 50},
)
data = res.json()
print(data["pagination"]["total"], "resolved markets")
```
</CodeGroup>
