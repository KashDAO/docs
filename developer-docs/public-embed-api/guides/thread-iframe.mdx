title: 'Market and Thread Iframes'
description: 'Embed a single Kash market or a whole thread of markets with an iframe'
---

Kash serves two iframe widgets that need no API calls at all:

| Widget | URL | Shows |
|---|---|---|
| Market | `https://app.kash.bot/markets/{marketId}/iframe` | One market card with live prices, a countdown and a predict button |
| Thread | `https://app.kash.bot/threads/{threadId}/iframe` | A thread's title and stats, plus a heatmap grid of all its markets ranked by volume |

Both take a UUID in the path. They read no query parameters. Any site may frame them, because they send `Content-Security-Policy: frame-ancestors *`. They are not indexed by search engines.

## Market iframe

```html
<iframe
  src="https://app.kash.bot/markets/93f1445c-912c-47b4-8065-d1ff5a6b8dfc/iframe"
  width="100%"
  height="520"
  frameborder="0"
  loading="lazy"
  allow="clipboard-write"
  title="Kash prediction market"
></iframe>
```

The card refreshes its prices live. Visitors choose an outcome and an amount, and the widget opens X with a prediction tweet already written, which the Kash trading bot reads to place the trade. If a new tab can't be opened, the widget asks your page to open the link (see [Events](#events)), and if that fails too, it copies the link to the clipboard. That clipboard fallback is why `allow="clipboard-write"` is recommended.

Get market IDs from [`GET /api/markets`](/developer-docs/public-embed-api/endpoints/markets).

## Thread iframe

```html
<iframe
  src="https://app.kash.bot/threads/00000001-0000-4000-a000-000000000003/iframe"
  width="100%"
  height="900"
  frameborder="0"
  loading="lazy"
  allow="clipboard-write"
  title="Kash prediction markets"
></iframe>
```

The thread widget shows:

- the thread's title, description, time remaining and total predictions
- an amount selector and a Yes/No toggle
- a heatmap grid of the thread's markets, highest volume first, loaded with `status=all` so ended markets still appear with their status

Visitors add Yes or No predictions on binary markets in the grid, then post them all in one tweet. Selecting a market tile, or predicting on a market with more than two outcomes, opens that market on app.kash.bot in a new tab.

Get thread IDs from [`GET /api/threads`](/developer-docs/public-embed-api/endpoints/threads). If a thread has no markets, the widget shows an empty state.

## Recommended attributes

| Attribute | Value | Why |
|---|---|---|
| `width` | `100%` | The widgets are responsive |
| `height` | 480 to 560 (market), 800 to 900 (thread) | Only the height needs fixing |
| `loading` | `lazy` below the fold | Avoids loading the widget before it's visible |
| `allow` | `clipboard-write` | Lets the clipboard fallback work |
| `title` | A description | Read out by screen readers |

If you sandbox the frame, the widget needs at least `allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox`, so it can run, call the API, and open X and market pages in new tabs. Don't grant `allow-top-navigation`. The widget never needs to navigate your page.

To shrink the frame on small screens, use a media query:

```css
@media (max-width: 768px) {
  .kash-thread-embed { height: 700px; }
}
```

If your site sets a Content Security Policy, allow the frame with `frame-src https://app.kash.bot`.

## Events

The widgets post messages to the parent window, addressed to your page's origin. Every message has the shape `{ type, data, origin: "https://app.kash.bot", timestamp }`:

| `type` | Sent by | `data` |
|---|---|---|
| `kash-iframe-ready` | Thread | `{ threadId, marketCount, totalVolume }` |
| `kash-market-clicked` | Thread | `{ threadId, marketId }` |
| `kash-tweet-share-attempt` | Market, thread | `{ templateId, contentType, privacy, characterCount, timestamp }` |
| `kash-tweet-share-success` | Market, thread | `{ templateId, url, timestamp }`: the X compose tab opened |
| `kash-open-twitter` | Market, thread | `{ url, type: "tweet-share", timestamp }`: the widget couldn't open a tab, so please open `url` yourself |
| `kash-tweet-share-fallback` | Market, thread | `{ templateId, fallbackMethod: "parent" \| "clipboard", url, timestamp }` |

```javascript
window.addEventListener('message', (event) => {
  if (event.origin !== 'https://app.kash.bot') return;
  const { type, data } = event.data ?? {};

  switch (type) {
    case 'kash-iframe-ready':
      console.log('Embed ready', data);
      break;
    case 'kash-open-twitter':
      window.open(data.url, '_blank', 'noopener');
      break;
    case 'kash-market-clicked':
      analytics.track('kash_market_click', { marketId: data.marketId });
      break;
  }
});
```

## Troubleshooting

- **"Not found" inside the frame.** The ID isn't a UUID or doesn't exist.
- **A thread shows no markets.** Check `GET /api/threads/{id}/markets?status=all`.
- **Nothing happens when a visitor predicts.** A sandbox without `allow-popups` blocks the X tab. Handle `kash-open-twitter`, or loosen the sandbox.
