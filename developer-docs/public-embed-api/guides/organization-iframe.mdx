title: 'Organization Iframe'
description: "Embed every market your organization runs with one iframe"
---

The organization widget shows **only your organization's markets** in a branded grid. Each card is a full market card with live odds and a predict button that opens X with the prediction tweet already written. You don't need any API calls.

## Quick start

```html
<iframe
  src="https://app.kash.bot/o/kash/iframe"
  width="100%"
  height="900"
  frameborder="0"
  loading="lazy"
  allow="clipboard-write"
  title="Our prediction markets"
></iframe>
```

Replace `kash` with your organization's slug or UUID.

## The organization identifier

The `{org}` segment of `https://app.kash.bot/o/{org}/iframe` accepts either:

- **a slug**: lowercase letters, digits and hyphens, up to 64 characters (for example `kash`)
- **a UUID**: the `organizationId` used by the JSON API

Both values are in [`GET /api/organizations/:id`](/developer-docs/public-embed-api/endpoints/organization-detail) as `slug` and `id`. If the identifier matches nothing, the widget shows a "not found" message instead of redirecting.

## What it shows

- Your organization's logo, display name and tagline
- The number of markets loaded so far
- A grid of your organization's **active** markets, including markets on which it is the partner, newest first. The data is the same as [`GET /api/organizations/:id/markets`](/developer-docs/public-embed-api/endpoints/organization-markets).
- 50 markets at a time, with a "load more" button. The grid scrolls inside the frame, so a taller frame shows more at once.

The organization is fixed by the URL, so another organization's markets never appear in your widget. The widget reads no query parameters.

## Recommended attributes

| Attribute | Value |
|---|---|
| `width` | `100%` |
| `height` | 700 to 900px |
| `loading` | `lazy` below the fold |
| `allow` | `clipboard-write` (fallback when a new tab can't be opened) |
| `title` | A description for screen readers |

The sandbox and Content Security Policy notes in [Market and Thread Iframes](/developer-docs/public-embed-api/guides/thread-iframe#recommended-attributes) apply here too.

## Events

Once the markets have loaded, the widget posts this message to your page:

```json
{ "type": "kash-iframe-ready", "data": { "organizationId": "6b617368-…", "marketCount": 47 }, "origin": "https://app.kash.bot", "timestamp": 1792526400000 }
```

Prediction actions on the cards send the same `kash-tweet-share-*` and `kash-open-twitter` messages as the market widget. They are listed in [Events](/developer-docs/public-embed-api/guides/thread-iframe#events).

```javascript
window.addEventListener('message', (event) => {
  if (event.origin !== 'https://app.kash.bot') return;
  if (event.data?.type === 'kash-iframe-ready') {
    console.log(`${event.data.data.marketCount} markets loaded`);
  }
});
```

## Building your own grid instead

To control the layout yourself, read the same data from the JSON API:

1. [`GET /api/organizations/:id`](/developer-docs/public-embed-api/endpoints/organization-detail) for branding
2. [`GET /api/organizations/:id/markets`](/developer-docs/public-embed-api/endpoints/organization-markets) for the markets
3. [`GET /api/markets/state?ids=…`](/developer-docs/public-embed-api/endpoints/markets-state) to keep the odds live
4. [`GET /api/markets/:id/twitter-link`](/developer-docs/public-embed-api/endpoints/market-twitter-link) for each "Predict" button

The [React example](/developer-docs/public-embed-api/examples/react) does exactly this.
