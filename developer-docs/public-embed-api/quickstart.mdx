You don't need an API key. You can make every request on this page from a terminal or a browser.

## Step 1: Find a market

List live markets and pick one:

```bash cURL
curl "https://app.kash.bot/api/markets?status=active&tradableOnly=true&limit=5"
```

```json Response (trimmed)
{
  "markets": [
    {
      "id": "93f1445c-912c-47b4-8065-d1ff5a6b8dfc",
      "title": "Will Ousmane Dembélé score against FC Barcelona?",
      "status": "ACTIVE",
      "chainId": 9000001,
      "tradable": true,
      "endTime": 1792530000000,
      "outcomes": [
        { "outcomeIndex": 0, "label": "Yes", "impliedChance": 0.2794 },
        { "outcomeIndex": 1, "label": "No", "impliedChance": 0.7206 }
      ],
      "organizationSlug": "kash"
    }
  ],
  "pagination": { "offset": 0, "limit": 5, "total": 47, "hasMore": true }
}
```

Copy the market's `id`.

## Step 2: Add the iframe

```html HTML
<iframe
  src="https://app.kash.bot/markets/{marketId}/iframe"
  width="100%"
  height="520"
  frameborder="0"
  loading="lazy"
  allow="clipboard-write"
  title="Kash prediction market"
  style="border: none; border-radius: 12px;"
></iframe>
```

Replace `{marketId}` with the ID from step 1. Any site can frame the embed pages. They send `Content-Security-Policy: frame-ancestors *`.

## Step 3: Embed every market an organization runs (optional)

The organization embed takes an organization slug or UUID and shows all of that organization's markets in a branded grid:

```html HTML
<iframe
  src="https://app.kash.bot/o/kash/iframe"
  width="100%"
  height="900"
  frameborder="0"
  loading="lazy"
  allow="clipboard-write"
  title="Kash prediction markets"
></iframe>
```

See [Organization iframe](/developer-docs/public-embed-api/guides/organization-iframe) and [Thread iframe](/developer-docs/public-embed-api/guides/thread-iframe) for the other widgets.

## Step 4: Listen for embed events (optional)

The thread and organization embeds post messages to the parent page. Each message is `{ type, data, origin, timestamp }`, and `type` always starts with `kash-`:

```javascript JavaScript
window.addEventListener('message', (event) => {
  if (event.origin !== 'https://app.kash.bot') return;
  const { type, data } = event.data ?? {};

  if (type === 'kash-iframe-ready') {
    console.log('Embed loaded', data); // { organizationId, marketCount } or { threadId, marketCount, totalVolume }
  }
  if (type === 'kash-market-clicked') {
    console.log('Market opened', data.marketId); // thread embed only
  }
});
```

## Step 5: Build your own UI (optional)

If you'd rather render markets yourself, read them from the JSON endpoints and add a "Predict on X" button with a [deep link](/developer-docs/public-embed-api/endpoints/market-twitter-link):

```javascript JavaScript
const marketId = '93f1445c-912c-47b4-8065-d1ff5a6b8dfc';
const res = await fetch(
  `https://app.kash.bot/api/markets/${marketId}/twitter-link?outcomeIndex=0&amount=10`
);
if (res.ok) {
  const { twitterUrl } = await res.json();
  window.open(twitterUrl, '_blank', 'noopener');
}
```

## Recommended sizes

| Embed | Width | Height |
|---|---|---|
| Single market | `100%` | 480 to 560px |
| Thread | `100%` | 800 to 900px |
| Organization | `100%` | 700 to 900px (scrolls inside the frame) |

## Troubleshooting

- **The embed shows "not found".** Check the ID. Market and thread embeds need a UUID. The organization embed accepts a slug or a UUID.
- **A thread embed shows no markets.** The thread has no live markets. Check with `GET /api/threads/{id}/markets`.
- **The deep-link endpoint returns `400`.** The market is no longer accepting predictions, because it isn't `ACTIVE` or it has expired.

</Note>
