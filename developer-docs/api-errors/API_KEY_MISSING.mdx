**HTTP status:** 401 · **Title:** "Authentication required"

## When it fires

An endpoint that requires authentication received a request with no `X-API-Key` header.

## Why it happens

- The request was sent without the header (most common on a first integration).
- A reverse proxy or HTTP client stripped the header.
- The wrong base URL. The documented endpoints live under `/v1/*`.

## How to fix

```http
GET /v1/portfolio HTTP/1.1
Host: api.kash.bot
X-API-Key: kash_live_<your-key-here>
```

- Send the key on every authenticated request. Keys are issued from the Kash app (Settings → API Keys).
- The full key is shown once, at issuance. If you have lost it, revoke it and issue a new one.

See [Authentication](/developer-docs/rest-api/authentication).

## Related codes
