**HTTP status:** 409 · **Title:** "Competition is not cancelled"

## When it fires

`POST /v1/competitions/{competitionId}/refund` was called for a competition that is not `cancelled`.

## Why it happens

A refund returns a contributor's own contribution, and a contribution is only owed back once the competition is cancelled. Before that:

- A **running** competition still legitimately holds the contribution; that is what entering paid for.
- A **settled** competition pays out through the prize claim (`POST /v1/competitions/{competitionId}/claim`), not this endpoint.

The check is enforced server-side for every refund, so this endpoint can never become a general withdrawal path on a live competition.

## How to fix

- Read the competition's `state`. If it is `running`, `registration` or `published`, there is nothing to refund yet.
- If it is `settled` or `paid_out`, claim the prize instead.
- Competitions are cancelled automatically when too few entrants join by the deadline, or by Kash. The refund then becomes available with no further action from you.
