**HTTP status:** 409 · **Title:** "Smart account not provisioned"

## When it fires

The account behind your API key does not have a fully set-up trading wallet yet, so nothing can be executed on-chain for it. Returned by `POST /v1/trades`, `POST /v1/redemptions` and `GET /v1/portfolio`.

What "set up" means depends on the market's chain. On EVM chains the account needs a completed smart account; on Solana the account's own wallet is used, and it must exist.

## Why it happens

- A new account that has not finished wallet setup in the Kash app.
- Wallet creation is asynchronous and has not completed yet.
- Rarely, the account's setup is incomplete on Kash's side; the `detail` says so and asks you to contact support.

## How to fix

- Finish onboarding in the Kash app. Wallet creation normally completes within a few seconds.
- If you set up recently, retry after about 30 seconds. If it persists for more than a minute, contact Kash support with the `requestId`.
