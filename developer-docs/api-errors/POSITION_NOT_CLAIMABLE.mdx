**HTTP status:** 409 · **Title:** "Position not claimable"

## When it fires

`POST /v1/redemptions` was called for a `(marketId, outcomeIndex)` that is not currently claimable for your account. Claimability is decided by the same rule the Kash app uses, so any claim the API accepts can be paid out.

## Why it happens

- **The outcome did not win.** On a resolved market only the winning outcome or outcomes pay out. Losing-outcome tokens can still show an on-chain balance but are worthless.
- **No refund for that outcome.** On a cancelled market, only outcomes with a non-zero refund price are refundable.
- **The market was paid out automatically.** It resolved before self-service redemption was enabled.
- **Already redeemed.** The position has been paid out, or a payout is in progress.
- **A previous claim failed.** An earlier claim for this exact position ended as `failed`, and a new claim cannot be created through the API until Kash clears it. The `detail` says so explicitly.

## How to fix

- Redeem the **winning** outcome index. On a cancelled market, redeem an outcome you hold that carries a refund.
- If the market was paid out automatically, your USDC is already settled; check `GET /v1/portfolio`.
- If a claim is **in progress** (not failed), repeating the request returns `200` with the original claim rather than this error.
- If a previous claim **failed**, contact Kash support so it can be cleared.
