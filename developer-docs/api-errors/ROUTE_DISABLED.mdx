**HTTP status:** 503 · **Title:** "Route disabled" · **Retry-After:** computed per response

## When it fires

One endpoint is temporarily unavailable. This is distinct from [`API_TRADE_PROCESSING_HALTED`](/developer-docs/api-errors/API_TRADE_PROCESSING_HALTED), which covers all API trade writes.

Example problem body:

```json
{
  "type": "https://docs.kash.bot/developer-docs/api-errors/ROUTE_DISABLED",
  "title": "Route disabled",
  "status": 503,
  "code": "ROUTE_DISABLED",
  "detail": "This endpoint is temporarily unavailable. Retry after the cooldown.",
  "instance": "/v1/markets/3f6c.../quote?outcomeIndex=0&amount=10",
  "requestId": "01HQGY8K2N3X4Z5C6D7E8F9G0H"
}
```

## How to fix

- Honour `Retry-After`. Polling faster will not re-enable the endpoint.
- Other endpoints are unaffected. If you don't need this one right now, carry on.
- For an endpoint critical to your integration, contact Kash support for an estimate.
- The TypeScript SDK raises this as `KashMaintenanceError`.
