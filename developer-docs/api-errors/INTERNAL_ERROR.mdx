**HTTP status:** 500 · **Title:** "Internal Server Error"

## When it fires

Something unexpected happened while handling the request. The cause is recorded on Kash's side, and the response carries no internal detail.

This is the catch-all. Every other code in this catalogue is an anticipated, structured failure; `INTERNAL_ERROR` means Kash hit something it had not categorised.

## Why it happens

- A genuinely unexpected condition.
- A server-side configuration fault (for example, a supported chain whose configuration is incomplete).
- A failure mode that does not yet have its own code. Please report it so Kash can add one.

## How to fix

- **Include the `requestId` in any support request.** It is Kash's handle into the logs and traces for your call.
- Retry once. If the problem was transient, the retry may succeed. Retry writes with the same `Idempotency-Key`.
- If it reproduces for a specific request, send Kash support the request shape (with secrets removed) and the `requestId`.
- The TypeScript SDK raises this as `KashServerError` with `requestId` set; raw HTTP callers can read `requestId` from the problem body.

## Related codes

Every other code in this catalogue is preferable. If you see `INTERNAL_ERROR` consistently for one operation, the right fix is for Kash to add a typed code, not for you to work around it.
