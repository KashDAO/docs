**HTTP status:** 404 · **Title:** "Redemptions not enabled"

## When it fires

`POST /v1/redemptions` was called in an environment where self-service redemption is not available. In that mode, winning positions in resolved markets are redeemed to holders' wallets automatically, without a claim.

## Why it happens

- Self-service redemption is not available in this environment, so winning positions are redeemed automatically at resolution.

This is distinct from [`ROUTE_DISABLED`](/developer-docs/api-errors/ROUTE_DISABLED), a temporary `503` for one endpoint. `REDEMPTIONS_NOT_ENABLED` means the capability is not available in this environment, so retrying will not help.

## How to fix

- Nothing to do as an integrator. Winning positions are still redeemed automatically once the market resolves; check `GET /v1/portfolio` for the settled balance.
- If you expected self-service redemption to be available, contact Kash support.
