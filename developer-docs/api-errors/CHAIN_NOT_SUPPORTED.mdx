**HTTP status:** 400 · **Title:** "Chain not supported"

## When it fires

The request targets a chain this environment does not support for the operation. There are three cases.

1. **A market on an unsupported chain.** `GET /v1/markets/{id}/quote` and `POST /v1/redemptions` read the chain, and the market is on a chain this environment cannot read.
2. **A Solana market on API version `2026-04-29`.** See below.
3. **A competition on an unsupported chain.** `POST /v1/competitions/{competitionId}/claim`, `/refund` and `/sponsor` return it when the competition's prize escrow runs on a chain where this environment cannot yet record claims, refunds or sponsorships.

### A Solana market on API version `2026-04-29`

`GET /v1/markets/{id}` and `GET /v1/markets/{id}/quote` return this code for a **Solana** market when the request does not send `X-Kash-Api-Version: 2026-08-19`, because `2026-04-29` has no field that can describe a non-EVM chain. It is returned **whatever the market's state**, so it does not mean the market is cancelled or closed.

Send `X-Kash-Api-Version: 2026-08-19`. The market then carries `chainRef`, `tradeable` and `notTradeableReason`, and an untradeable market's quote or trade returns [`MARKET_NOT_TRADEABLE`](/developer-docs/api-errors/MARKET_NOT_TRADEABLE) (409) instead. `POST /v1/trades` does not use this code for Solana markets on either version.

## Why it happens

The market or competition is on a chain this environment does not support for the operation. Your request is well formed; this is a chain-support condition, so it is a permanent `400` and retrying will not help. (A supported chain with incomplete server configuration returns [`INTERNAL_ERROR`](/developer-docs/api-errors/INTERNAL_ERROR) instead.)

## How to fix

- **Solana markets:** send `X-Kash-Api-Version: 2026-08-19`. Production trading runs on Solana.
- **Other market routes:** the `detail` field lists the supported chains.
- **Competition routes:** confirm the competition runs on a chain this environment supports for prize escrow.
- If you believe the chain should be supported, contact Kash support. It is a server configuration gap, not something you can correct.
