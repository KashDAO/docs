**HTTP status:** 409 · **Title:** "Competition prize claim failed"

## When it fires

`POST /v1/competitions/{competitionId}/claim` authorised your claim, but the payout for it is recorded as `failed`. No prize was paid.

## Why it happens

An earlier payout attempt for this exact prize ended in a final `failed` state. It still occupies the claim, so it cannot be re-attempted through the API.

## How to fix

- Contact Kash support with the `requestId`. Kash must clear the failed payout before a new claim can succeed. Retrying the request will not change the outcome.
