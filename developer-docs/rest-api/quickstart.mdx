This guide runs against **staging** (`api-staging.kash.bot`, Solana devnet). Going live is the same flow against `api.kash.bot` with a `kash_live_` key.

## 1. Create a Kash account

Sign up at [staging.kash.bot](https://staging.kash.bot). The account you create owns your API keys and the smart account your trades run from.

## 2. Create an API key

In the app, open **Settings → API Keys** and create a key:

1. Name it (for example `local dev`).
2. Choose its scopes. For this guide: `markets:read`, `markets:quote`, `trades:read` and `trades:write`. See [scopes](/developer-docs/rest-api/authentication#scopes).
3. Optionally set an IP allowlist.
4. Optionally set a webhook URL to receive trade events (step 7).

The key is shown **once**:

```bash
export KASH_API_KEY="kash_test_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
export KASH_API="https://api-staging.kash.bot/v1"
```

## 3. List markets

The API serves `2026-08-19` by default. The examples send `X-Kash-Api-Version: 2026-08-19` to pin it, so a future default change cannot alter your integration. See [API versions](/developer-docs/rest-api/overview#api-versions).

```bash
curl "$KASH_API/markets?status=ACTIVE&limit=5" \
  -H "X-API-Key: $KASH_API_KEY" \
  -H "X-Kash-Api-Version: 2026-08-19"
```

Pick a market whose `tradeable` is `true`. `403 INSUFFICIENT_SCOPE` means the key lacks `markets:read`; `429` means you hit your rate limit (see `Retry-After`).

## 4. Get a quote

```bash
MARKET_ID="<a market id from step 3>"

curl "$KASH_API/markets/$MARKET_ID/quote?outcomeIndex=0&action=buy&amount=10000000" \
  -H "X-API-Key: $KASH_API_KEY" \
  -H "X-Kash-Api-Version: 2026-08-19"
```

The quote `amount` is in **atomic USDC** (`10000000` is 10 USDC). The response gives `quote.tokensOut` (outcome tokens, 18 decimals), `quote.effectivePrice` and `quote.impliedProbability`, plus `market.tradeable`.

## 5. Place a trade

Your smart account needs USDC for a buy.

```bash
curl -X POST "$KASH_API/trades" \
  -H "X-API-Key: $KASH_API_KEY" \
  -H "X-Kash-Api-Version: 2026-08-19" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
    "marketId": "'"$MARKET_ID"'",
    "outcomeIndex": 0,
    "amount": "10",
    "side": "buy",
    "metadata": { "source": "quickstart" }
  }'
```

The trade `amount` is a **decimal USDC string** (`"10"` is 10 USDC), unlike the atomic amount in the quote. The answer is `201 Created`:

```json
{
  "trade": { "id": "…", "status": "pending", "correlationId": "…", "chainRef": "solana:devnet", "txHash": null, "…": "…" },
  "data":  { "…": "same as trade" },
  "_meta": { "requestId": "…", "timestamp": "…", "idempotent": false }
}
```

The status moves `pending → validating → executing → completed`, or ends in `failed` or `rejected`.

## 6. Watch it complete

```bash
TRADE_ID="<the id from step 5>"

curl "$KASH_API/trades/$TRADE_ID" \
  -H "X-API-Key: $KASH_API_KEY" \
  -H "X-Kash-Api-Version: 2026-08-19"
```

When it completes, `txHash` holds the Solana transaction signature and `tokensOut` the tokens received. Rather than polling, use a webhook.

## 7. Receive a webhook

If the key has a webhook URL, a `trade.completed` event was POSTed to it:

```json
{
  "id": "…",
  "type": "trade.completed",
  "apiVersion": "2026-08-19",
  "createdAt": "…",
  "data": {
    "tradeId": "…",
    "marketId": "…",
    "chainRef": "solana:devnet",
    "outcomeIndex": 0,
    "amount": "10",
    "side": "buy",
    "status": "completed",
    "txHash": "5VERv8NMvzbJMEkV8xnrLkEaWRtSz9CosKDYjCJjBRnbJLgp8uirBgmQpjKhoR4tjF3ZpRzrFmBV6UjKdiSZkQUW",
    "tokensOut": "18734012471176000000",
    "metadata": { "source": "quickstart" }
  }
}
```

With these headers:

```
X-Kash-Signature:   t=1792000000000,v1=<hex-hmac-sha256>
X-Kash-Event-Id:    <same as the body id>
X-Kash-Event-Type:  trade.completed
X-Kash-Api-Version: 2026-08-19
```

Always verify the signature before acting on an event. See [Verifying signatures](/developer-docs/rest-api/webhooks/verifying).

## 8. Use the SDK

The TypeScript SDK handles headers, versions, retries, idempotency and webhook verification:

```bash
npm install @kashdao/sdk
```

```ts
import { KashClient } from '@kashdao/sdk';

// A kash_test_ key is routed to staging automatically.
const kash = new KashClient({ apiKey: process.env.KASH_API_KEY! });

const trade = await kash.trades.create({
  marketId,
  outcomeIndex: 0,
  amount: '10',
  side: 'buy',
  metadata: { source: 'quickstart' },
});

const final = await kash.trades.waitForCompletion(trade.id);
console.log(final.status, final.txHash);
```

Full reference: [TypeScript SDK](/developer-docs/rest-api/sdks/typescript).
