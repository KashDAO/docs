All atomic-USDC amounts are decimal **strings** (6 decimals). A competition that does not exist and one that is still a draft get the same answer, `404 COMPETITION_NOT_FOUND`.

## The competition resource

| Field                 | Type              | Notes |
| --------------------- | ----------------- | ----- |
| `id`                  | uuid              | |
| `organizationId`      | uuid              | The organization running it. |
| `slug`, `name`, `summary`, `rules` | string | |
| `bannerUrl`           | string \| null    | |
| `state`               | enum              | `published`, `registration`, `running`, `claim_window`, `cancelled`, `scoring_frozen`, `settled`, `paid_out`, `closed`. |
| `settlementMode`      | enum              | `onchain_escrow`, `sponsored`, `offchain_airdrop`, `none`. |
| `isVerified`          | boolean           | |
| `chain`               | enum              | `solana`, `evm`, `none`. |
| `solanaCompetitionId` | string \| null    | The on-chain competition id (a u64, so a string). |
| `advertisedPotAtomic` | string            | The prize the creator promised. Editorial only: it is never checked against escrow. |
| `potFundedAtomic`     | string \| null    | What escrow actually holds, **net** of on-chain fees. |
| `potAvailableAtomic`  | string \| null    | `potFundedAtomic` less what has been paid out or refunded. |
| `entryTargetAtomic`   | string \| null    | The **gross** per-entry buy-in target. Not comparable with the net pot figures. |
| `submissionOpensAt`, `joinDeadline`, `startsAt`, `endsAt` | date-time | |
| `claimDeadline`, `publishedAt`, `cancelledAt`, `settledAt` | date-time \| null | |

`potFundedAtomic`, `potAvailableAtomic` and `entryTargetAtomic` are `null`, never `"0"`, unless the competition is an on-chain escrow on Solana (`settlementMode: onchain_escrow` and `chain: solana`). Read `null` as "does not apply". Pay attention to which figure you show: a prize is paid from the funded pot, not the advertised one.

## `GET /v1/competitions`

Newest first, cursor-paginated. Drafts are never listed.

| Query    | Type    | Notes |
| -------- | ------- | ----- |
| `cursor` | string  | |
| `limit`  | integer | 1 to 100, default 20. |
| `state`  | enum    | Any state above. `draft` is refused with `400 VALIDATION_FAILED`. |
| `chain`  | enum    | `solana`, `evm`, `none`. |

Response `200`: `{ data: Competition[], pagination, _meta }`.

## `GET /v1/competitions/{competitionId}`

Response `200`: `{ competition, data, _meta }`.

## `GET /v1/competitions/{competitionId}/entrants`

Every entry, including entries still collecting their buy-in. Ordered by `entrantId`, cursor-paginated; `limit` is 1 to 500, default 200, because a roster is bounded by one competition.

Each item: `{ entrantId, competitionId, subjectType, groupId, userId, isCaller, subjectName, subjectSlug, subjectAvatarUrl, entryState, onBoard, chain, fundedGrossAtomic, entryTargetAtomic, remainingAtomic, rosterCapturedAt, updatedAt }`.

- `subjectType` is `user` or `group`. `userId` is your own user id on your own `user` entry and `null` on every other row; `isCaller` marks your entry.
- `entryState` is `applied`, `funding`, `joined`, `accepted`, `withdrawn`, `rejected`, `refunded` or `disqualified`. `onBoard` is true only for entries on the scoreable board (`joined` or `accepted`).
- `fundedGrossAtomic`, `entryTargetAtomic` and `remainingAtomic` are gross figures for the buy-in race. They are `null` together for any competition that runs no Solana funding race.

## `GET /v1/competitions/{competitionId}/leaderboard`

The standings, best rank first. Once scoring is final this is the frozen board that decided the prizes. Cursor-paginated on `(rank, entrantId)`; `limit` is 1 to 500, default 200.

Each item: `{ competitionId, entrantId, subjectType, groupId, userId, isCaller, subjectName, rank, realizedPnlAtomic, accuracyBps, totalVolumeAtomic, updatedAt }`. `rank` is a dense rank, so tied entrants share it. `realizedPnlAtomic` is signed. `accuracyBps` and `updatedAt` are `null` for an entrant who has never scored.

## `POST /v1/competitions/{competitionId}/join`

Creates an entry in `funding` with a zero stake. Joining does not pay: the entry becomes scoreable once its members have pooled the minimum entry fee through `/contribute`.

| Body field      | Type     | Notes |
| --------------- | -------- | ----- |
| `subjectType`   | `user` \| `group`, required | A `user` entry is always for you. |
| `groupId`       | uuid     | Required for a `group` entry. Only the group's owner may enter it. |
| `subjectName`   | string, required | 1 to 120 characters. |
| `payingAddress` | string, required | A Solana (base58) or EVM (`0x`) address. |

Response `201`: `{ entry: { competitionId, entrantId, subjectType, entryState: "funding", joinedAt }, data, _meta }`.

Errors: `403 COMPETITION_NOT_GROUP_OWNER`, `409 COMPETITION_ALREADY_ENTERED` (fund the existing entry instead), `409 COMPETITION_ENTRY_NOT_FUNDABLE`.

## `POST /v1/competitions/{competitionId}/contribute`

Records your contribution to an entry's pooled fee. The contributing member is always you, never a body field. The entry moves to `joined`, and its roster is captured, the moment the pool reaches the minimum entry fee.

| Body field      | Type     | Notes |
| --------------- | -------- | ----- |
| `entrantId`     | uuid, required | |
| `amountAtomic`  | string, required | Integer string. Must meet the competition's minimum ticket. |
| `payingAddress` | string, required | Solana or EVM address. |
| `externalRef`   | string, required | The on-chain transfer id, 1 to 200 characters. This is the idempotency key for the money: repeating the same `externalRef` credits nothing. |

Response `200`: `{ contribution: { competitionId, entrantId, memberContributionAtomic, entryFundedAtomic, entryState, contributedAt }, data, _meta }`. `memberContributionAtomic` is your running total.

Errors: `400 COMPETITION_CONTRIBUTION_BELOW_MINIMUM`, `403 COMPETITION_NOT_ENTRY_MEMBER`, `409 COMPETITION_ALREADY_IN_ANOTHER_ENTRY`, `409 COMPETITION_CONTRIBUTION_REF_CONFLICT` (the `externalRef` was used for a different amount), `409 COMPETITION_ENTRY_NOT_FUNDABLE`.

## `POST /v1/competitions/{competitionId}/sponsor`

Adds your organization's money to the prize pot. There is no sponsor address in the body: it is resolved from your API key's organization, and it is the address a cancelled competition's prefund can be reclaimed by. Only `onchain_escrow` and `sponsored` competitions accept sponsorship, and only before settlement.

| Body field     | Type   | Notes |
| -------------- | ------ | ----- |
| `amountAtomic` | string, required | Integer string. |
| `externalRef`  | string, required | The on-chain transfer id and idempotency key, 1 to 200 characters. |

Response `200`: `{ sponsorship: { competitionId, organizationId, amountAtomic, sponsoredAt }, data, _meta }`.

Errors: `409 COMPETITION_SPONSOR_NO_SMART_ACCOUNT`, `409 COMPETITION_ENTRY_NOT_FUNDABLE`, `409 COMPETITION_CONTRIBUTION_REF_CONFLICT`, `400 CHAIN_NOT_SUPPORTED`.

## `POST /v1/competitions/{competitionId}/claim`

Claims your prize or airdrop from a settled competition. Send an empty JSON object as the body. A repeat claim returns the same recorded claim.

Response `200`: `{ claim: { competitionId, entrantId, amountAtomic, kind, round, claimedAt }, data, _meta }`. `kind` is `prize` or `airdrop`.

Errors: `403 COMPETITION_PRIZE_NOT_CLAIMABLE` (you own no winning entry, or more than one), `409 COMPETITION_NOT_SETTLED`, `409 COMPETITION_PRIZE_AUTO_DISTRIBUTED` (prizes are distributed automatically for this competition), `409 COMPETITION_PRIZE_CLAIM_FAILED`, `400 CHAIN_NOT_SUPPORTED`.

## `POST /v1/competitions/{competitionId}/refund`

Returns your own contributions from a **cancelled** competition. There is no body: the amount is worked out from your contributions, net of refunds already paid. In a pooled group entry each member is refunded their own contribution.

Response `200`: `{ refund: { competitionId, refunds: [{ entrantId, amountAtomic }], totalRefundedAtomic, partial, refundedAt }, data, _meta }`.

Errors: `404 COMPETITION_NOTHING_TO_REFUND` (also the answer to a repeat call, or to a non-contributor), `409 COMPETITION_NOT_CANCELLED` (a settled competition pays through `/claim`), `409 COMPETITION_REFUND_FAILED`, `400 CHAIN_NOT_SUPPORTED`.
