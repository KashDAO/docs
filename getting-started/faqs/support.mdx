# Getting support

<AccordionGroup>
  <Accordion title="How do I contact Kash support?">
    - **In the app:** tap the info button → **Feedback**. If you're signed in, your report opens a support chat in **Messages**, and Kash Support replies there
    - **Email:** [support@kash.bot](mailto:support@kash.bot)
    - **Community:** ask in [Discord](https://discord.com/invite/n9eumqjMPb)
  </Accordion>

  <Accordion title="What should I include?">
    - What you were trying to do and what happened instead
    - The market, amount and time
    - Any transaction link or error message
    - A screenshot or short video

    Never include your private key or login codes. Kash will never ask for them.
  </Accordion>

  <Accordion title="Which channel should I use?">
    - **Account or funds issues:** in-app feedback or support@kash.bot
    - **How-to questions:** these docs, then Discord
    - **Security vulnerabilities:** see [Reporting security issues](/getting-started/faqs/security)
  </Accordion>
</AccordionGroup>

# Bugs and ideas

<AccordionGroup>
  <Accordion title="How do I report bugs or suggest features?">
    Tap the info button → **Feedback**, then choose **Report a bug** or **Share an idea**. Anonymous feedback is welcome too, but we can only reply if you're signed in.
  </Accordion>
</AccordionGroup>
